Short description
- Personal portfolio site showcasing projects, skills, and contact information for Mahesh Singh Madai.

Files
- `index.html`, `header.html`, `footer.html`, `projects.html`, `skills.html`, `experience.html`, `styles.css`, `script.js`

Quick preview
1. Open `index.html` in a browser for a local preview.
2. Or view the live site at the demo link above.

Deploy / Update
- This site is hosted on GitHub Pages. To update the live site:

```powershell
git add .
git commit -m "Update site"
git push origin main
```

Notes
- Ensure asset paths are relative so pages work under `/portfolio-website-mahesh-madai/`.
- If you use includes (`header.html`/`footer.html`), confirm they're inlined or loaded client-side.
